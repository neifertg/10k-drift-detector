# Drafted briefs

`draft-briefs` writes two kinds of file here:

- `overview.json` — cross-sector themes, plus one or two takeaways for each sector
- `sectors/<sector>.json` — one brief per peer pair
- `token-usage.json` — input and output tokens for each API request. It is a log, not a brief.

Do not put a brief here by hand. A quote that is not in the stored filing extract fails `verify-briefs` and is left off the report.

This folder is empty of drafts until that command has been run. The pages in `docs/` say so.
